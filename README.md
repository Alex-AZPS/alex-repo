# alex-repo

This repository serves as the issue tracker for the [AZURECLIPS](https://github.com/users/Alex-AZPS/projects/1) project  a **public reference implementation** of how we manage cross-team engineering work using GitHub Projects V2.

##  Purpose

The original [CLIPS](https://github.com/orgs/Azure/projects/957) project dashboard is private. This public replica demonstrates:

- **Epic  Feature  Task** hierarchy using GitHub sub-issues
- **Squad-based views** for team-specific tracking (Identity, Observability, Platform Eng, Q&P, Experience Enablement)
- **Custom fields**: Status, Size, Priority, Estimate (day)
- **Sprint & Kanban views** for agile workflows

- **[Epic]**  High-level initiatives spanning multiple features
- **[Feature]**  Deliverable capabilities under an Epic
- **[Task]**  Actionable work items
